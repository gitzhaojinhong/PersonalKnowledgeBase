# 图算法

Neo4j Graph Data Science（GDS）库提供 65+ 种图算法，涵盖中心性、社区检测、路径查找、相似度、节点嵌入、链接预测等类别。GDS 通过内存图投影将图数据加载到优化过的数据结构中，实现高性能分析。GDS 2.x 是当前主推版本。

## GDS 基础

### 图目录

GDS 使用图目录（Graph Catalog）管理内存中的图投影。每个投影有唯一名称，算法通过名称引用图。`gds.graph.list()` 查看所有投影。

### 内存图投影

`gds.graph.project()` 将 Neo4j 中的节点和关系投影到内存图。指定节点标签和关系类型，GDS 自动构建内存图。

```cypher
CALL gds.graph.project(
  'myGraph',
  'Person',
  { KNOWS: { orientation: 'UNDIRECTED' } }
)
```

### Cypher 投影

`gds.graph.project.cypher()` 使用 Cypher 查询灵活定义投影的节点和关系，支持复杂的数据过滤和转换。

```cypher
CALL gds.graph.project.cypher(
  'myGraph',
  'MATCH (p:Person) RETURN id(p) AS id',
  'MATCH (p1:Person)-[r:KNOWS]->(p2:Person) RETURN id(p1) AS source, id(p2) AS target'
)
```

### 算法执行模式

算法支持三种执行模式：`stream`（返回结果流）、`write`（写回 Neo4j 属性）、`mutate`（写入内存图但不写回数据库）。`mutate` 适合链式算法调用。

### 变异模式

`mutate` 模式将结果写入内存图属性，后续算法可直接使用，无需写回数据库。所有算法链执行完毕后，使用 `gds.graph.writeNodeProperties()` 一次性写回。

## 中心性算法

中心性算法衡量节点在图中的重要性。重要性可以基于度（Degree Centrality）、最短路径上的位置（Betweenness Centrality）、邻居的重要性（PageRank）等不同维度。

### PageRank

基于随机游走的节点重要性算法，节点的重要性取决于指向它的节点的重要性和数量。应用于搜索引擎排名、推荐系统、影响力分析。

```cypher
CALL gds.pageRank.stream('myGraph', { maxIterations: 20, dampingFactor: 0.85 })
YIELD nodeId, score
RETURN gds.util.asNode(nodeId).name AS name, score
ORDER BY score DESC
```

### ArticleRank

PageRank 的变体，降低低出度节点的权重传递，更适合引用网络场景。

### Betweenness Centrality

基于最短路径的中心性，衡量节点作为"信息桥梁"的重要性。计算成本高，适合中小规模图。

### Closeness Centrality

节点到所有其他节点的平均最短路径长度的倒数，衡量节点到图中各点的"接近程度"。

### Degree Centrality

最简单的中心性，衡量节点的直接连接数。分为入度中心性、出度中心性和总度中心性。

### Eigenvector Centrality

衡量节点连接的重要性，不仅是连接数量，更关注连接节点的质量。适用于社交网络影响力分析。

### Harmonic Centrality

Closeness Centrality 的变体，处理了不连通图时 Closeness 为无穷大的问题。

### HITS

Hub 和 Authority 两个维度的中心性。Hub 指向大量 Authority，Authority 被大量 Hub 指向。适用于网页排名和学术引用网络。

## 社区检测

### Louvain

基于模块度优化的分层社区检测算法。检测速度快，适合大规模图，是最常用的社区检测算法之一。

```cypher
CALL gds.louvain.stream('myGraph')
YIELD nodeId, communityId
RETURN gds.util.asNode(nodeId).name AS name, communityId
```

### Leiden

Louvain 的改进版本，保证社区内部连通性，避免 Louvain 可能出现的不连通社区。质量更高，速度略慢。

### Label Propagation

基于标签传播的快速社区检测，每个节点采纳邻居中最多的标签。速度极快，但结果可能不稳定。

### Weakly Connected Components

查找无向连通分量，用于识别图中互不连通的子图群组。计算效率高。

### Strongly Connected Components

查找有向图中的强连通分量，每个分量内任意两点可以互相到达。适用于有向图分析。

### K-Means Clustering

基于节点属性的聚类算法，将节点分为 K 个簇。适用于属性图的聚类分析。

### Triangle Count

统计每个节点参与的三角形数量，衡量节点所在社区的紧密程度。聚类系数（Clustering Coefficient）基于三角形计数。

### Local Clustering Coefficient

单个节点的聚类系数，衡量节点邻居之间相互连接的紧密程度。

### Modularity

衡量社区划分质量的指标，值越高表示社区内部连接紧密、社区间连接稀疏。Louvain 和 Leiden 算法以最大化模块度为目标。

### K-Core Decomposition

将图分解为 K 层核心，每层中的节点至少有 K 个邻居。用于识别图的骨架结构和核心节点。

## 路径查找

### Dijkstra

经典最短路径算法，基于边权重计算两个节点之间的最短路径。需要权重属性。

```cypher
MATCH (source:City {name: '北京'}), (target:City {name: '上海'})
CALL gds.shortestPath.dijkstra.stream('myGraph', {
  sourceNode: source,
  targetNode: target,
  relationshipWeightProperty: 'distance'
})
YIELD index, nodeId, totalCost
RETURN index, gds.util.asNode(nodeId).name, totalCost
```

### A*

A-Star 搜索算法，使用启发式函数加速路径查找，适合坐标空间中的最短路径。

### Yen's k-Shortest Path

查找两个节点之间的 K 条最短路径，适用于需要备选路径的场景。

### BFS

广度优先搜索，按层遍历图，适合查找最短跳数路径（无权图）。

### DFS

深度优先搜索，沿路径深入到末端再回溯，适合路径探索。

### All Pairs Shortest Path

所有节点对之间的最短路径，计算成本极高，适合小规模图。

### Minimum Spanning Tree

最小生成树，连接所有节点的最小权重边集合。适用于网络设计和成本优化。

### Steiner Tree

斯坦纳树，连接指定节点集合的最小权重树，适用于物流和网络设计。

### Maximum Flow

最大流算法，计算从源节点到汇节点的最大流量。适用于网络容量分析和资源分配。

## 相似度算法

### Node Similarity

基于共同邻居的节点相似度，使用 Jaccard 或 Overlap 系数。适用于推荐系统中的"相似用户"发现。

```cypher
CALL gds.nodeSimilarity.stream('myGraph', { topK: 10 })
YIELD node1, node2, similarity
RETURN gds.util.asNode(node1).name, gds.util.asNode(node2).name, similarity
```

### K-Nearest Neighbors

基于节点属性计算 K 个最近邻居，用于相似度搜索和推荐。

### Jaccard

Jaccard 相似系数，衡量两个节点邻居集合的交集占并集的比例。

### Cosine

余弦相似度，基于节点属性向量计算，适用于高维空间中的相似度度量。

### Pearson

皮尔逊相关系数，衡量两个节点属性向量的线性相关性。

### Overlap

Overlap 系数，衡量两个节点邻居集合的交集占较小集合的比例。

## 节点嵌入

### Node2Vec

基于随机游走和 Skip-gram 的节点嵌入算法，将图结构信息编码为低维向量。适用于下游机器学习任务。

### FastRP

快速随机投影嵌入算法，速度极快，适合大规模图。通过随机投影和归一化生成节点嵌入向量。

```cypher
CALL gds.fastRP.stream('myGraph', { embeddingDimension: 128 })
YIELD nodeId, embedding
RETURN gds.util.asNode(nodeId).name, embedding
```

### GraphSAGE

基于图神经网络的归纳式节点嵌入，支持未见过的节点。适用于动态图和新节点嵌入。

### 嵌入应用

节点嵌入用于下游任务：节点分类、链接预测、聚类分析、可视化。嵌入向量可以存储为节点属性，配合向量索引实现语义搜索。

## 链接预测

### Adamic Adar

基于共同邻居特征的链接预测指标，对稀有邻居给予更高权重。

### Common Neighbors

最简单的链接预测方法，两个节点的共同邻居越多，越可能产生链接。

### Preferential Attachment

基于度的链接预测，度数高的节点更可能产生新链接。

### Resource Allocation

基于资源分配的链接预测，模拟资源从源节点沿网络传递到目标节点的方式。

## Pregel API

### 自定义算法

GDS 提供 Pregel API，允许用户用类似 Pregel 的"以顶点为中心的编程模型"实现自定义图算法。用户定义计算逻辑，GDS 负责迭代和消息传递。

### 计算模型

每个节点维护一个值，每轮迭代中节点接收邻居消息、更新自身值、发送新消息给邻居。迭代直到收敛或达到最大迭代次数。

### 消息传递

节点间通过消息传递信息，消息在每轮迭代中聚合后传递给目标节点。聚合函数支持 `sum`、`min`、`max` 等。

## 机器学习管道

### 节点分类

GDS 支持节点分类管道，包括数据分割（训练/测试）、特征提取、模型训练（Logistic Regression、Random Forest）和预测。通过 `gds.beta.pipeline.nodeClassification` 创建管道。

### 链接预测

链接预测管道预测节点间是否应该存在关系。通过 `gds.beta.pipeline.linkPrediction` 创建管道，自动生成特征、训练模型和评估。

### 属性预测

预测节点的属性值，类似传统机器学习中的回归任务。通过 `gds.alpha.pipeline.nodeRegression` 创建管道。

### 模型选择

管道支持多种算法作为候选模型，通过 `addLogisticRegression()`、`addRandomForest()` 等方法添加。管道自动选择性能最优的模型。

## Python 客户端

### 安装配置

`graphdatascience` 包，通过 `pip install graphdatascience` 安装。客户端封装了 Neo4j Python Driver，简化 GDS 操作。

```python
from graphdatascience import GraphDataScience
gds = GraphDataScience("bolt://localhost:7687", auth=("neo4j", "password"))
```

### 算法调用

Python 客户端 API 与 Cypher 过程 API 一一对应，返回 Pandas DataFrame 或 GDS 对象。

```python
G, result = gds.graph.project("airline", "City", "HAS_FLIGHT_TO")
result = gds.pageRank.stream(G)
```

### 结果处理

Python 客户端的图、模型、管道对象提供便捷方法，减少手动管理资源的复杂度。`G.name()`、`G.node_count()` 等方法直接获取元数据。
